# PP-P02. Пакет матеріалів

**Тема:** if/elif/else та логічні вирази  
**Час:** 1 контактна академічна година (45 хв) + 1 година самостійно  
**Передумови:** PP-L03

Працюйте зі стартовим файлом і карткою свого варіанта. PDF-інструкція лежить поруч із цим каталогом у `../PP-P02_Практична.pdf`.

Файли:

- `student_starter.py — стартовий файл без розв’язку`
- `student_variants.json — картки без відповідей`
- `README.md — ця коротка інструкція`

Запуск: `python student_starter.py VARIANT_1_30`. Оберіть номер 1–30 і виконайте всі контрольні приклади з PDF. Здайте файл `p02_vNN.py` та `report.md` з номером варіанта, кодом, вісьмома запусками й перевіркою двох меж.
